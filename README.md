# PresenGo

**PresenGo** is a student attendance management application designed to provide a more structured, practical, and efficient approach to attendance management.

The project aims to develop a digital attendance system with a focus on simplicity, usability, and reliable data management. Built with Java, PresenGo is designed to evolve into a more complete and maintainable application.

## Overview

Attendance management is an important part of academic activities. However, conventional attendance processes can be time-consuming and difficult to manage efficiently.

PresenGo aims to simplify this process through a digital system that supports attendance recording and student data management.

## Key Objectives

- Simplify student attendance management.
- Provide a structured approach to storing and managing student information.
- Build a maintainable application using Object-Oriented Programming principles.
- Establish a foundation for future attendance features and improvements.

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Apache NetBeans or another Java IDE
- Maven

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/USERNAME/PresenGo.git
   ```

2. Open the project in Apache NetBeans.
3. Allow Maven to resolve the required dependencies.
4. Run `App.java` to launch the JavaFX application.

For console-based attendance testing, run `MainPresensi.java` separately.
